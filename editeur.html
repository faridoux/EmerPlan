Plan électrique interactif

Groupes

    Mode d'emploi

    • Naviguer : glisser = déplacer, molette = zoomer, clic sur un chiffre = surbrillance du groupe.
    • Ajouter zones : cliquer sur le plan pour poser une zone (saisir le numéro du groupe, ex. 1, 2, L1...). Glisser une zone = la déplacer. Clic droit dessus = la supprimer.
    • Tracer chemins : cliquer pour poser les points du chemin (le fil), double-clic = terminer et saisir le numéro du groupe. Clic droit = retirer le dernier point. Échap = annuler.
    • Ajouter rectangles : cliquez-glissez pour dessiner un rectangle, relâchez et saisissez le numéro du groupe. Il entrera en surbrillance avec les autres éléments du même numéro.
    • Supprimer : clic droit sur un chemin ou un rectangle (dans n'importe quel mode) = le supprimer. En mode « Ajouter zones », clic droit sur une zone = la supprimer. Le « x » du menu de gauche supprime un groupe entier.
    • En navigation, les chemins sont invisibles tant qu'aucun groupe n'est sélectionné ; passez en mode « Tracer chemins » ou « Ajouter zones » pour tous les voir.
    • Surbrillance : cliquer sur une zone (ou un groupe à gauche) met en évidence toutes les zones et chemins portant le même numéro ; le reste est estompé. Cliquez dans le vide ou appuyez sur Échap pour désactiver.
    • Les données sont sauvegardées automatiquement dans le navigateur. Exporter enregistre un fichier .json de sauvegarde.
